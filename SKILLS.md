# Project skills

The workspace currently contains these skills in `.agents/skills/`:

| Skill | Use it for |
| --- | --- |
| `find-skills` | Finding an installable skill when the workspace lacks a needed capability. |
| `frontend-design` | Distinctive visual direction and frontend design decisions. |
| `grill-with-docs` | An opt-in interview that records the current domain and decisions in docs. |
| `ui-ux-pro-max` | Design-system, interaction, accessibility, responsive, motion, and stack guidance. |
| `web-design-guidelines` | A final review of changed interface files against web interface guidelines. |

Use the three frontend skills together for user-facing UI work. `grill-with-docs` is optional and only runs when explicitly requested.
